# Unmind

Public bilingual rules site for **Unmind**, built with the [Resonance site template](https://github.com/aleascript/resonance-site-template) and Docusaurus.

## Local development

```bash
npm install
npm run start:en
npm run start:fr
```

To preview the complete bilingual site as it will be deployed:

```bash
npm run preview
```

Validate types and both locales:

```bash
npm run check
```

The canonical working rules currently live in Notion. Reader-facing material is consolidated into `docs/en/` and `docs/fr/`.
