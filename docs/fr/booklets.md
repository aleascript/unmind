# Livrets

> **Six livrets, six verbes, six manières de tenter de rester au monde.**

Un livret ne désigne pas ce qu’une personne *est*. Il désigne ce qu’elle a appris à *faire* pour continuer à vivre avec les autres, jusqu’au moment possible où ce geste devient sa seule réponse.

## Pourquoi des verbes

**Veiller, servir, plaire, s’effacer, ordonner et résister** sont des gestes immédiatement humains. Chacun peut être attention, générosité, intelligence ou courage. Chacun peut également se rigidifier, envahir toutes les relations et refermer le monde.

> Le syndrome d’Unmind ne réside pas dans le verbe : il est commun à tous les personnages. Le verbe décrit une manière singulière de rester au monde, qui se referme lorsqu’elle devient la seule réponse encore disponible.

Cette formulation maintient les pensionnaires proches de nous. Elle évite que les livrets deviennent six diagnostics déguisés ou six catégories d’altérité.

## Les six gestes

| Livret | Geste de survie | Risque de fermeture |
| --- | --- | --- |
| **[Veiller](veiller.md)** | Anticiper le danger pour que rien ne surprenne plus. | Tout devient signe avant-coureur ; se reposer revient à abandonner quelqu’un. |
| **[Servir](servir.md)** | Devenir nécessaire pour ne pas être abandonné. | N’exister qu’à travers les besoins des autres ; provoquer parfois le besoin que l’on sait combler. |
| **[Plaire](plaire.md)** | Réguler l’autre par le charme, l’humour ou l’accord. | Ne plus pouvoir supporter le désaccord, le silence ou un visage devenu illisible. |
| **[S’effacer](s-effacer.md)** | Ne pas offrir de prise. | Devenir introuvable même pour ceux qui voudraient rejoindre, aimer ou protéger. |
| **[Ordonner](ordonner.md)** | Rendre le monde prévisible par les règles, les signes ou les rituels. | Confondre la cohérence construite avec la réalité et vivre toute exception comme une menace. |
| **[Résister](resister.md)** | Préserver son existence par le refus et l’opposition. | Ne plus pouvoir reconnaître une main tendue sans y percevoir une tentative d’emprise. |

## Architecture commune

Chaque livret propose un langage propre pour les cinq profondeurs :

- **Masque** — comment ce verbe me rend encore lisible aux autres ;
- **Protection** — comment je l’utilise pour ne pas être atteint ;
- **Attachement** — pour qui ou pour quoi ce geste conserve encore un sens ;
- **Blessure** — autour de quelle rupture il s’est organisé ;
- **Monde intérieur** — quelle réalité privée apparaît lorsque ce verbe devient une loi du monde.

Chaque joueur construit **deux fils personnels**. Pour chaque fil, il choisit un fragment à chaque profondeur. Un même fragment ne peut être choisi deux fois.

## Principe de différenciation

Les six livrets ne proposent pas six pouvoirs. Ils conduisent les joueurs à **remarquer des choses différentes dans une même situation**.

Face à une porte laissée ouverte :

- Veiller cherche ce qui peut entrer ;
- Servir cherche qui aura besoin qu’on la ferme ;
- Plaire regarde la réaction des autres ;
- S’effacer cherche comment passer sans être vu ;
- Ordonner remarque la rupture de procédure ;
- Résister se demande qui prétend décider si elle doit rester ouverte.

## Garde-fous

- Aucun livret ne correspond à un diagnostic clinique.
- Le Monde intérieur n’est pas la vérité cachée du personnage.
- Le Masque n’est pas nécessairement faux.
- La Blessure n’est pas une explication causale suffisante.
- Le verbe peut sauver le personnage autant qu’il peut l’enfermer.
- Deux personnages construits avec le même livret peuvent être radicalement différents.
