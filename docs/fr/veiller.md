# Veiller

> **Anticiper le danger pour que rien ne surprenne plus.**

Ce livret explore un geste humain qui protège, relie et soutient — puis peut devenir la seule manière encore disponible de répondre au monde.

## Le geste humain

Veiller, c’est prêter attention, protéger, se souvenir de ce que les autres oublient et rester présent lorsque quelqu’un est vulnérable. Ce geste peut être une forme profonde d’amour et de responsabilité.

## Sa fermeture latente

Le geste se referme lorsque l’incertitude devient intolérable. Se reposer ressemble alors à une faute ; déléguer, à un abandon. Tout événement risque de devenir un avertissement que les autres refusent encore de voir.

## Couleur des cinq profondeurs

| Profondeur | Direction |
| --- | --- |
| **Masque** | Je remarque ce que les autres ne voient pas ; je préviens, je prépare, je reste éveillé. |
| **Protection** | Je surveille les issues, mémorise les horaires, répète les vérifications ou imagine toujours le pire avant qu’il arrive. |
| **Attachement** | Quelqu’un, un lieu ou une promesse dépend encore de ma vigilance. |
| **Blessure** | Une fois, je n’ai pas vu venir ; je suis arrivé trop tard ; personne ne m’a cru quand il était encore temps. |
| **Monde intérieur** | Les détails annoncent le danger. Tant que je veille, la catastrophe demeure en suspens. |

## Ambivalences à préserver

- protéger quelqu’un / le contrôler ;
- percevoir un danger réel / fabriquer une cohérence entre les signes ;
- désirer enfin dormir / ne faire confiance à personne pour prendre le relais.

Aucun fil ne devrait résoudre ces tensions à l’avance.

## Banque de fragments

:::note

Choisir un fragment ne fixe pas une histoire complète. Sa relation avec les autres profondeurs sera créée secrètement par le joueur, puis découverte en jeu.

:::

### Masque

- Je connais le nom de tous ceux qui passent cette porte.
- Je dors toujours le plus près de la sortie.
- Je préviens avant même qu’on me demande.
- Je remarque aussitôt ce qui a changé.

### Protection

- Je vérifie trois fois ce que les autres disent avoir vérifié.
- J’imagine d’abord le pire ; ainsi, il ne me surprend pas.
- Je reste éveillé quand les autres baissent leur garde.
- Je garde toujours une issue et un témoin en vue.

### Attachement

- Quelqu’un compte sur moi pour rentrer vivant.
- La chambre voisine ne doit jamais rester silencieuse trop longtemps.
- Je conserve la montre de celui que je devais réveiller.
- Je veille sur une promesse que personne d’autre ne se rappelle.

### Blessure

- J’ai cru qu’il dormait encore.
- Une fois, j’ai ri quand on m’a demandé de l’aide.
- Tout le monde disait qu’il n’y avait aucun danger.
- On m’avait confié une seule chose, et j’ai détourné les yeux.

### Monde intérieur

- Les accidents préviennent toujours quelqu’un avant d’arriver.
- Quand toutes les portes sont fermées, quelque chose choisit une fenêtre.
- Si je m’endors le premier, demain ne sera pas le même.
- Les lumières clignotent pour compter ceux qui manquent.
